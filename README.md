# Time Tracker (PWA)
Deploy this folder to any HTTPS host (Netlify Drop, Vercel, Cloudflare Pages, GitHub Pages).
Local test: `python3 -m http.server 8000` then open http://localhost:8000
Install: Android Chrome -> Install app. iPhone Safari -> Share -> Add to Home Screen.
On every update change VERSION in sw.js (v1 -> v2).
