# ⏱️ Time Tracker PWA

A lightweight, responsive **Time Tracking Progressive Web App (PWA)** for tracking working sessions, projects, time entries, billable hours, and earnings.

The application is built with **HTML, CSS, and Vanilla JavaScript** and uses the browser's **Local Storage** for client-side data persistence.

---

## ✨ Features

- ⏱️ Start / Stop time tracking
- 📁 Project management
- 📝 Add notes to time entries
- 💰 Track billable hours and earnings
- 📊 Daily and weekly time statistics
- 📋 View and manage time logs
- ✏️ Edit existing time entries
- 🗑️ Delete time entries
- ↩️ Undo supported actions
- 🎨 Light / Dark / Auto theme support
- 💱 Configurable currency
- 📱 Fully responsive interface
- 📲 Installable as a Progressive Web App
- 🔌 Works without a backend
- 💾 Data stored locally in the browser

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **Web Storage API**
- **Service Worker**
- **Web App Manifest**
- **Progressive Web App (PWA)**

No frontend framework or backend server is required.
